# Notepade — блокнот на C#

Десктопный текстовый редактор на C# (.NET, WinForms).

## Возможности
- открытие текстовых файлов через системный диалог (OpenFileDialog)
- сохранение текстовых файлов (SaveFileDialog)
- фильтрация по типу файла: только *.txt

## Стек
- C#, .NET, WinForms
- Git

## Как запустить
1. Клонировать репозиторий: `git clone https://github.com/kostyastarrus-hash/Notepade.git`
2. Открыть `bloknotnut.slnx` в Visual Studio
3. Нажать F5
